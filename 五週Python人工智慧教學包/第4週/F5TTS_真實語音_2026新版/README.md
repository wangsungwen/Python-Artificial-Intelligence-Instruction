# 第四週新版：F5-TTS 真實語音與多語字幕影片

以前三週 Python 語法為基礎，12 個單元、180 分鐘，依序執行 Colab GPU 模型、生成 WAV、SRT、PNG、MP4 和成果 ZIP。沒有 DummyF5TTS 或模擬聲音，教材實際的模型相容性、GPU 下載及 FFmpeg 影片生成尚未完成線上端到端測試。

此資料夾的 Word、PPTX、Notebook 及 ZIP 為 GitHub 同步版，根據原學生版課程重組，並非此前聊天下載二進位檔的逐位元複製。字幕是人工撰寫、場景級對齊，不是自動翻譯或逐字 ASR。

需要 Colab T4 GPU、授權參考聲音、網路、FFmpeg 和 F5-TTS。
